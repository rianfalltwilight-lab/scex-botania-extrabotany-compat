# SCEX Botania / ExtraBotany Compatibility 1.3.0

This unofficial BOTH-side NeoForge bridge targets Minecraft 1.21.1,
NeoForge 21.1.248, Botania 456-20260822.093314-4, and exactly
[SCEX ExtraBotany 2.0-scex.5-dev](https://github.com/rianfalltwilight-lab/scex-extrabotany/releases/tag/v2.0-scex.5-dev).

It restores forest-wand selection and binding for ExtraBotany flowers, prevents
the ExtraBotany pool interceptor from consuming an in-progress normal Botania
binding, and persists pool-to-Manalink links on the logical server.

Install the same JAR on client and server. This bridge is not bundled into
ExtraBotany and must not be paired with another ExtraBotany version.

Validation: 2/2 contract tests, 7/7 physical-client server assertions, persisted
bindings after world reopen, a clean minimal dedicated-server stop, and zero new
errors in the 236-JAR SCEX acceptance server. See `VALIDATION.md` for limits.

OpenAI Codex materially assisted implementation analysis, testing,
documentation, public-source review, and release preparation under maintainer
supervision. Publication does not deploy anything to a production server.
